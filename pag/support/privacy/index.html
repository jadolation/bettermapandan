Privacy Policy

How we handle data on the Better Mapandan civic transparency portal.

Overview

Better Mapandan is an independent civic transparency portal. It is not an official government website and is not affiliated with, endorsed by, or operated by the Municipality of Mapandan or any government agency. We collect minimal data and are committed to protecting your privacy.

Information We Collect

Automatically collected: When you visit Better Mapandan, our hosting provider (GitHub Pages) may collect standard web server logs including your IP address, browser type, referring URL, and pages visited. This is standard server operation and is not used to identify individual visitors.

Search queries: The search functionality runs entirely in your browser. Your search queries are never sent to a server or stored.

Language preference: If you use the language switcher (when available), your preference is stored locally in your browser and is never transmitted to us.

How We Use Information

We do not use, sell, or share personal information. Server logs are used only for maintaining the website and understanding usage patterns in aggregate.

Cookies

Better Mapandan does not use cookies. The language preference is stored using localStorage, which is a browser-only storage mechanism and is not transmitted to any server.

Third-Party Services

The site loads the following external resources:

  • Google Fonts (fonts.googleapis.com) — for font loading
  • Open-Meteo API (open-meteo.com) — for weather data (loaded only on the homepage)
  • Leaflet / OpenStreetMap — for the interactive map (loaded only on the homepage)

These services have their own privacy policies. We do not share any personal data with them.

Data Sources

All government data presented on this site is compiled from publicly available official sources. This data is already public and is presented here for informational purposes.

Changes to This Policy

This privacy policy may be updated from time to time. Changes will be posted on this page with an updated date.

Contact

For privacy-related inquiries, please open an issue on our GitHub repository or use the report form.

# Better Mapandan GIS V3.1 — Implementation handoff

This package contains the V3.1 plan, 15-barangay ADM4 candidate GeoJSON and preview, two barangay reference maps, and four **original historical physical map posters**. Source/reference inputs remain preserved. Repository implementation is in progress outside this source package; prepared outputs and their measured registration limitations belong under `datasets/GIS/physical/prepared/`, not in these originals.

Read `GIS_IMPLEMENTATION_PLAN_V3_1.md` and `docs/gis.md` from the repository root. The poster preparation date is **2021-12-15**, not 2012; underlying thematic-data vintage is unknown. Both raw shapefile sets include DBFs. Do not stretch entire posters into arbitrary bounds or claim independent geographic accuracy from grid registration alone. Final build/browser verification is reported separately from this implementation-status note.

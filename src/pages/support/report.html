Support

Report Incorrect Information

Help us keep the data accurate. Report errors, outdated information, or missing data.

How to report

Choose the method that works best for you. All reports are reviewed by our volunteer team.

Option 1: Email

Send an email with the following details:

  • Page URL: The page where you found the error
  • Error description: What is incorrect
  • Correct information: If you know the correct data
  • Source: Where you found the correct information (if available)
Compose email →

Option 2: GitHub Issue

For developers and technical users, file an issue on our GitHub repository with the label "data-correction".

Open GitHub issue →

What happens next?

  1. Review: Our volunteers review the report within 7 days.
  2. Verification: We cross-reference the correction with official government sources.
  3. Update: If verified, the information is updated on the site.
  4. Acknowledgment: We credit contributors (unless they prefer anonymity).

Verification status

Every piece of data on Better Mapandan includes a verification status label:

Official

Data from official government sources (COA, PSA, DILG).

Verified

Data independently verified against multiple official sources.

Community Verified

Data confirmed by community members with local knowledge.

Needs Verification

Data that has not yet been independently verified.

Placeholder

Estimated data pending official figures. Clearly marked.

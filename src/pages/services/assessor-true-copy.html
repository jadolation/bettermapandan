Description

The Municipal Assessor's Office issues certified true copies of Tax Declarations upon request. The Tax Declaration is an official document showing the assessed value of real property for taxation purposes. The client submits a written request with the property details. The Assessor's Office locates the record, prepares the certified true copy, and releases it upon payment.

Requirements

  • Written request stating the property location (lot number, block, street, barangay)
  • Valid Government-issued ID

Procedure

  1. Submit a written request with property details and valid ID to the Assessor's Office.
  2. Staff receives and verifies the request (5 min).
  3. Staff locates the Tax Declaration in the records (5 min).
  4. Staff prepares the certified true copy and stamps it (3 min).
  5. Pay ₱100 at the Treasury Office and claim the document (2 min).

Service Details

Responsible Office: Municipal Assessor's Office (MASSO)

Classification: Simple

Processing Time: 15 minutes

Fee: ₱100 per certified true copy

Where to Apply: Municipal Assessor's Office, Main Municipal Building, Poblacion

Description

The MPDC provides public information and data to clients who request specific information about Mapandan's planning, land use, and development data. The MPDC verifies the availability of the requested data and provides it if available. This service supports transparency and public access to government information.

Requirements

  • Letter request
  • Valid ID

Procedure

  1. Present request letter and photocopy of valid ID to MPDC staff.
  2. MPDC staff verifies the availability of the requested data/information.
  3. If available, MPDC provides the requested data/information.
  4. Receive the information/data.

Service Details

Responsible Office: Municipal Planning and Development Office (MPDC)

Classification: Simple

Processing Time: ~13 minutes

Fee: Free

Where to Apply: MPDC Office, Main Municipal Building, Poblacion

Contact: (075) 696-0831

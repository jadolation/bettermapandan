Accessibility Statement

Our commitment to making government information accessible to all residents.

Our commitment

Better Mapandan is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards.

Conformance Status

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at the AA level. These guidelines explain how to make web content more accessible for people with disabilities.

Measures Taken

We have implemented the following accessibility features across the site:

  • Semantic HTML structure
  • Skip-to-content navigation link
  • Visible focus indicators
  • Sufficient color contrast (4.5:1 minimum)
  • Keyboard-accessible navigation
  • Screen-reader-friendly labels
  • Descriptive link text
  • Proper heading hierarchy

Accessibility features

Keyboard Navigation

All interactive elements are accessible via keyboard. Use Tab to move between elements, Enter to activate links and buttons, and Escape to close overlays.

Screen Readers

The site uses semantic HTML, ARIA labels, and proper heading hierarchy to ensure screen readers can navigate the content effectively.

Color & Contrast

All text meets WCAG AA contrast requirements. Information is never conveyed through color alone — icons, labels, and text are always provided alongside color coding.

Text Resizing

The site uses relative units (rem, em) for text sizing. Users can resize text up to 200% without loss of content or functionality.

Forms

All form inputs are associated with labels. Error messages are descriptive and programmatically associated with the relevant input fields.

Tables

Data tables include proper header associations (<th scope>), captions where appropriate, and are responsive on mobile devices.

Known limitations

We are aware of the following accessibility limitations and are working to address them:

  • PDF documents: Some linked government documents (COA reports, provincial issuances) may not be fully accessible. We provide HTML summaries where possible.
  • Interactive maps: The Leaflet map is navigable via keyboard but may present challenges for screen reader users. We provide alternative text descriptions and a data table fallback.
  • Third-party content: Embedded content from external government websites may not meet the same accessibility standards.
